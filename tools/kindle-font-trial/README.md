# Isolated indexed font experiment

The operator authorized a temporary Library document on November 20, and
subsequently authorized unattended measurement, evidence-based optimization
and deployment/retest. The pre-existing WeRead item is not an A/B selector.
`freeze.py` creates one new, distinctly named document and one common
supervisor for the two retained ARM builds. The only change to its app launch
is explicit demo/offline data, route, exit deadline and optional capture.
The two-second power wait, both orientation queries and display ownership
remain in the production launcher. No external service or cloud book is used.

Run the host tools on `test-env`, using the shared build userspace for
compilation and Pillow, but the **host** for the physical lease and SSH.
Do not install the experiment scripts as an ordinary Kindle package.
`peer-files.txt` covers public files only: the Aidoku owner's
[R3 installed identities](https://github.com/moooyo/aidokuForKindle/blob/3d8f0d7d5d2981d56f9df08c092fbd35fd33f8d2/docs/review/startup-r3-qualification-20261119-8baf57f/release/installation.json)
supersede the three corresponding older files. The unchanged entries come
from the owner's November 18 `stable_entry` / `state_snapshot` declarations.
The BiliComics owner accepted its 16:11 read-only absence inventory for
immediate recheck. Drift stops the batch; no peer path is restored or deleted.
The hard registry checks are the approved single handler command and the
published shell MIME association. The decoded selected rows must also remain
identical across the batch. Neither check claims to reproduce the lost
November 18 serialization or to freeze the whole device registry.

The stage is a fresh owner-marked directory on `/mnt/us`. The document must
be absent along with its sidecars and catalog rows before publication. A/B
share the document, boot, settings, launcher, helpers, clocks and public
seed. Before each request the worker restores a new copy of the seed,
stabilizes for eight seconds and arms exactly one use of the document. The
ARM helper samples `CLOCK_MONOTONIC` immediately before invoking the native
file-URI service. The first accepted business-frame SEND is timestamped in
that same device clock. Neither SSH latency nor receipt polling enters the
measurement. Actual tap time and optical completion are not observed.

Independent A/B Library and Reader cases check the route, stable active
scanout and software snapshot. A half-turn can align scanout, but inversion
is not accepted; ambiguous alignment is rejected. Body MAE must be at most
8 against each arm's software frame, with the opposite orientation at least
3 levels worse. Between arms the software/physical body limits are 0.1/0.5
gray levels; the dynamic status edges are excluded. Timed runs do not
request software captures. After SEND each timing run corroborates the
Library using a small active-page thumbnail; its same-arm reference must be
within 5 gray levels and at least 3 closer than the Reader. This check is
not the timing endpoint.

Exclude A0 and B0, then measure `AB, BA, AB, BA, AB, BA`. Keep incomplete
runs and slower pairs. Promotion requires all route, pixel, recovery and
protection gates, positive median paired request-to-SEND savings, at least
five faster pairs and passing host font tests. Do not mix other startup
changes into that promotion. A successful indexed comparison still requires
a normal-entry post-deployment check. Permission to clear application data
does not make a reset necessary.

`prepare_rollout.py` is specific to that archived font-only binary; it must
not deploy it over a package that also enables orientation reuse. Build new
daily packages with `scripts/build-kindle.sh`, not the historical promotion tool.

Use `test_trial.py` in the worker userspace to rehearse one-shot selection,
clock validation and fresh/partial/foreign stage behavior. During the
physical batch, `run.py` uses the existing host lease protocol, pinned SSH
and private authentication. It verifies case/entry ownership before
cleanup, waits for the scanner to remove only its test row, and releases
only the matching lease. If interrupted after a write, use its private
attempt with `--recover`; do not clear a live or unknown lock. Local copies
of stock screens, private application data, host keys and tokens are not
experiment outputs.
